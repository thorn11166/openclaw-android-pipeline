      res/mipmap-anydpi-v26/ — adaptive icons for API 26+ (recommended)
      res/mipmap-anydpi/     — shape drawable fallbacks for API 24–25
      res/drawable/          — background and foreground vector drawables

  proguard-rules.pro (missing)
    build.gradle.kts release config references this file explicitly.
    Release builds fail with "file not found".
    Fixed: created with standard keep rules for AndroidX, Parcelable, enums.

  gradle/wrapper/gradle-wrapper.properties (missing)
    Without this, `./gradlew` cannot bootstrap Gradle at all.
    Fixed: created, pinning Gradle 8.4.

  gradle.properties (missing)
